# Evento React - MAWR EventHub

Projeto desenvolvido como trabalho acadêmico do curso técnico, utilizando React.js.

## 📋 Sobre o Projeto

Sistema de gerenciamento de eventos com funcionalidades de cadastro, calendário, promoções e perfil de usuário, com cadastro de eventos, senhas e muito mais.

## ⚙️ Funcionalidades
- Cadastrar eventos
- Verificar eventos na agenda 

## 🚀 Tecnologias Utilizadas

- React.js
- CSS
- HTML

## 💻 Instalação

```
- bash
- npm install
- npm install material-icons
- npm start

```
